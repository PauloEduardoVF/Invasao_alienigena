# 👾 Invasão Alienígena

Projeto de estudo desenvolvido em Python durante a leitura e prática do livro **Curso Intensivo de Python**.

O objetivo deste projeto foi aplicar conceitos de programação através do desenvolvimento de um jogo, praticando organização de código, lógica, módulos e orientação a objetos.

## 📚 Sobre o projeto

O jogo coloca o jogador no controle de uma nave que precisa enfrentar uma frota de alienígenas.

Durante o desenvolvimento, o projeto foi dividido em vários arquivos para organizar melhor as responsabilidades do código.

## ▶️ Como executar

Clone o repositório:

```bash
git clone https://github.com/PauloEduardoVF/Invasao_alienigena.git
```

Entre na pasta:

```bash
cd Invasao_alienigena
```

Instale o Pygame:

```bash
pip install pygame
```

Execute o jogo:

```bash
python alien_invasion.py
```

Em alguns sistemas, pode ser necessário usar:

```bash
python3 alien_invasion.py
```
