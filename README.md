# 👾 Alien Invasion (Invasão Alienígena)

Um jogo arcade 2D desenvolvido em Python usando a biblioteca Pygame. Este projeto foi construído com o objetivo de aplicar conceitos de Programação Orientada a Objetos (POO), gerenciamento de estados e desenvolvimento de sistemas interativos.

## ✨ Funcionalidades
* Movimentação fluida da nave do jogador em tempo real.
* Sistema de disparos contínuos para destruir a frota alienígena.
* Aumento progressivo de velocidade e dificuldade à medida que as frotas são eliminadas.
* Sistema de pontuação dinâmico, contagem de níveis e rastreamento de recorde máximo (High Score).

## 🚀 Tecnologias Utilizadas
* **Python 3**
* **Pygame**
